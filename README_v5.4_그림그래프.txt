MathOCR Teacher Pro v5.4 — Graph / Figure Preservation
======================================================

핵심 수정
---------
기존:
그래프 안의 y=4, y=k, A, B, C, D, O, x 등을 OCR이 본문으로 풀어써서
원본 그래프가 사라지는 문제가 있었습니다.

v5.4:
1. 사용자가 '그림'으로 지정한 영역을 원본 PDF/이미지에서 직접 잘라냅니다.
2. 같은 페이지의 해당 문제와 자동 연결합니다.
3. HWP 생성 시 그래프/기하도형/표를 원본 이미지 그대로 삽입합니다.
4. 그림은 HWP 파일 내부에 임베드됩니다.
5. AI OCR에는 그림 내부의 축 문자/점 이름/수식을 본문으로 다시 나열하지 않도록 지시합니다.
6. 수학 본문은 기존 native HWP EquationCreate 방식을 유지합니다.

권장 사용법
-----------
문제 전체: '문제'로 드래그
그래프/도형/표: 그 위를 '그림'으로 별도 드래그
→ HWP로 변환

그림 영역이 문제 박스 안에 있으면 해당 문제에 우선 연결합니다.
문제 박스 밖에 있어도 같은 페이지에서 가장 가까운 문제에 연결합니다.
